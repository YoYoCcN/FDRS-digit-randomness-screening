# Contributing

Contributions are welcome.

## Suggested contribution types

- Bug reports
- Code optimization
- Additional visualization modules
- Additional benchmark datasets
- Documentation improvements
- Reproducibility tests across R versions

## Before submitting a pull request

1. Make sure the code runs from a clean R session.
2. Avoid uploading sensitive, unpublished, or non-shareable raw data.
3. Document all changes clearly.
4. Preserve the interpretation boundary: FDRS is a screening tool, not a misconduct detector.
